# User Stories — FleetWise

## Critérios de priorização

As User Stories foram selecionadas com base em:

- **Valor de negócio:** impacto direto na redução de custos.
- **Viabilidade técnica:** possibilidade de implementação nas Sprints disponíveis.
- **Cobertura de personas:** atendimento às necessidades de gestor, CFO e Sem Parar.

---

## US01 — Consolidar custos de diferentes fontes

**Como** gestor de frota  
**Quero** importar dados de múltiplas fontes e formatos  
**Para** visualizar o custo total da operação em um único ambiente

### Critérios de aceitação

- [ ] Aceita CSV, Excel, PDF, imagem e texto
- [ ] Categoriza automaticamente as despesas
- [ ] Valida dados inconsistentes
- [ ] Exibe resumo por categoria

---

## US02 — Identificar ineficiências operacionais

**Como** gestor de frota  
**Quero** identificar veículos e categorias com custos acima do esperado  
**Para** priorizar ações de melhoria

### Critérios de aceitação

- [ ] Calcula custo por veículo e por km
- [ ] Detecta outliers estatísticos
- [ ] Exibe alertas visuais
- [ ] Permite drill-down por veículo

---

## US03 — Estimar economia potencial

**Como** CFO  
**Quero** visualizar o impacto financeiro das oportunidades  
**Para** tomar decisões de investimento

### Critérios de aceitação

- [ ] Compara com benchmarks de mercado
- [ ] Calcula economia em reais
- [ ] Apresenta ROI estimado
- [ ] Considera diferentes cenários

---

## US04 — Receber recomendações priorizadas

**Como** gestor de frota  
**Quero** receber um plano de ação claro  
**Para** executar melhorias de forma organizada

### Critérios de aceitação

- [ ] Classifica por impacto e urgência
- [ ] Sugere ações específicas
- [ ] Relaciona com soluções Sem Parar (quando aplicável)
- [ ] Permite exportar plano

---

## US05 — Trabalhar com dados incompletos

**Como** usuário  
**Quero** receber análise mesmo com informações parciais  
**Para** iniciar o diagnóstico rapidamente

### Critérios de aceitação

- [ ] Gera estimativa com nível de confiança
- [ ] Indica dados faltantes
- [ ] Sugere fontes adicionais
- [ ] Melhora com novos dados

---

## US06 — Acompanhar evolução temporal

**Como** gestor ou CFO  
**Quero** comparar custos ao longo do tempo  
**Para** verificar eficácia das ações

### Critérios de aceitação

- [ ] Armazena histórico de análises
- [ ] Gera comparações mês a mês
- [ ] Exibe tendências em gráficos
- [ ] Permite filtrar por período
